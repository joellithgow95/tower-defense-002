# Documentation instructions
Read the local README first, then only relevant documents. Preserve existing implementation and roadmap distinctions. Use relative links and update indexes. Capture ideas freely; formalize deliberately.
Use statuses exploratory, proposed, accepted, superseded. Only human collaborators can accept significant creative decisions. A merged exploratory document is not automatically canon. Record significant decisions in decisions/ with context, rationale, implications and open questions. Update affected domain documents when decisions are accepted; retain superseded records. Surface contradictions rather than inventing resolutions. Use Markdown and simple frontmatter (id, title, status, created, updated) for substantive new documents. Follow root AGENTS.md.
