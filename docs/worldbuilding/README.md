# The Lyth
The founding discussion proposes a fantasy region inspired by the Lithgow surname's place-name interpretation, a damp hollow by a lake. The gray dog is a separate folk-etymological inspiration, not a literal translation.
## Terminology
- **The Lyth:** regional name, endorsed in discussion.
- **Old Lyth:** forgotten territory/ecosystem being rediscovered; exact boundaries and history unresolved.
- **Lythgoe:** town or surviving remnant within the region; name endorsed, precise nature unresolved.
